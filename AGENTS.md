# AGENTS.md

## Projet

Ce repository contient le portfolio professionnel de **Mouhamet Thiam**.

Le portfolio présente un profil :

**Software & Systems Engineer**

avec une orientation :

**Développeur Backend / Full Stack Junior**

Le profil couvre principalement :

- Software Engineering ;
- développement Backend / Full Stack ;
- développement web ;
- DevOps ;
- Docker & CI/CD ;
- systèmes ;
- réseaux ;
- infrastructure ;
- monitoring.

Le projet est développé volontairement avec :

- HTML5 ;
- CSS3 ;
- JavaScript vanilla.

L'objectif est de construire un portfolio professionnel, crédible, moderne, maintenable et performant.
